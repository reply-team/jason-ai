# The jason commands the desktop's chat never runs, one per line.
#
# The listed commands are refused by the host's tool fence, and a command that names a listed operation is refused by
# the desktop. A person runs them, in the page or in a terminal. An operation is told from a command by its dot.
#
# The command lines below are written from ConfinedVerbs.Table by DesktopDenyListTests, the table the CLI refuses under
# JASON_CONFINED; a line taken out or added here by hand is red there until JASON_UPDATE_FIXTURES=1 writes the file
# again. The operation lines are checked against the Runtime API and the verbs, and are edited by hand.
#
# The verbs that are a person's own word: an approval approved or rejected, a standing approval, a decision answered, a
# preference, a block cleared, work resumed, a report and a subscription rewound. The CLI gives them no default actor,
# and gives none to four verbs further down either.
approval approve
approval reject
approval set-standing
approval unset-standing
decision answer
preference set
preference unset
block clear
workitem resume
report submit
subscription rewind
#
# The verbs that change the installation, follow it without end, or carry it off the machine:
runtime
plugin install
plugin reload
profile
skills
update
uninstall
ui
session
journal watch
export
import
#
# The verbs the CLI gives no default actor that change who is reached or what runs: taking someone off the
# do-not-contact register, changing which plugin performs an operation, and changing which profile a role runs on.
suppression remove
route set
route unset
plugin grant
plugin revoke
role set-profile
#
# The verbs the chat refuses beyond the CLI's own table: adding a role, whose entry command the dispatcher starts when
# work names the role, and linking a project's folder, which then becomes a working folder of every chat on the
# project's campaigns.
role add
project link
