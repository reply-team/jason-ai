# The jason commands the desktop's chat never runs in Plan only, one per line.
#
# In Plan only the listed commands are refused by the host's tool fence, and a command that names a listed operation is
# refused by the desktop; there a person runs them, in the page or in a terminal. An operation is told from a command
# by its dot. In Ask first, Auto-edit and Full access the turn's mode decides each instead (modeFence in
# desktop/src/chat-deny.ts).
#
# The command lines below are written from ConfinedVerbs.Table by DesktopDenyListTests, the table the CLI refuses under
# JASON_CONFINED; a line taken out or added here by hand is red there until JASON_UPDATE_FIXTURES=1 writes the file
# again. The operation lines are checked against the Runtime API and the verbs, and are edited by hand.
#
# The verbs that are a person's own word: an approval approved or rejected, a standing approval, a decision answered, a
# preference, a campaign's send mode, a block cleared, work resumed, today's launch limits lifted, a send reviewed, a
# report and a subscription rewound. The CLI gives them no default actor, and gives none to eight verbs further down
# either.
approval approve
approval reject
approval set-standing
approval unset-standing
decision answer
preference set
preference unset
campaign set-send-mode
block clear
workitem resume
launches lift
workitem review
report submit
subscription rewind
#
# The verbs that change the installation, follow it without end, or carry it off the machine:
runtime
plugin install
plugin reload
profile
skills
update
uninstall
install
ui
session
journal watch
export
import
#
# The verbs the CLI gives no default actor that change who is reached or what runs: taking someone off the
# do-not-contact register, changing which plugin performs an operation, granting a plugin something or taking a
# grant back, changing which profile a role runs on, and turning a notification channel on or off.
suppression remove
route set
route unset
plugin grant
plugin revoke
role set-profile
notification enable
notification disable
#
# The verbs the chat refuses beyond the CLI's own table: adding a role, whose entry command the dispatcher starts when
# work names the role, linking a project's folder, which then becomes a working folder of every chat on the
# project's campaigns, starting a campaign or resuming one, which is what lets its queued work run, and archiving
# one, which no verb undoes: it cancels its open work but a search's stop, with each item's approval whether still
# asked or already given, stops its running attempts once the archive is committed, and cancels its pending questions.
role add
project link
campaign start
campaign archive
