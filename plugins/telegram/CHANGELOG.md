# Changelog

This package versions independently of the Jason runtime, under SemVer.

## 1.0.0

First release. Performs the delivery contract `notification.send` version 1: Jason's pointer, sent as plain text to one
Telegram chat by a bot, with the bot's token from `Plugins:Config:telegram` or `TELEGRAM_BOT_TOKEN`. What it does not do,
and why, is in [README.md](README.md).
