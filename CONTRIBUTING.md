# Contributing

This repository is Jason, whole: the runtime and its CLI, the skills that teach an agent the job, the plugins that
carry operations to providers, the operation contracts, the install scripts, and every release. All of it is developed
here, in the open.

Where to write:

- **A problem** — something that does not work, or works otherwise than a page says: open an
  [issue](https://github.com/reply-team/jason-ai/issues/new?template=problem.yml) with the file `jason doctor` wrote
  attached; the form asks which version you ran (`jason --version`), on which platform, what you ran and what it
  answered. A file made with `--include-journal` never goes to an issue.
- **A question or an idea**: start a [discussion](https://github.com/reply-team/jason-ai/discussions).
- **Help with your own installation**: write to **support@reply.io**; [Getting help](README.md#getting-help) says what
  to send.
- **A vulnerability**: never anywhere public; [SECURITY.md](SECURITY.md) says where it goes.

Everything here is MIT ([LICENSE](LICENSE)).
