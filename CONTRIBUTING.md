# Contributing

This repository is the published copy of Jason's open parts — the skills, the plugins, the operation contracts, the
install scripts and the documentation a user, an operator or a plugin author needs — together with every release of
the runtime.

It is written by Jason's release process, not by hand: each release opens one pull request here that brings this tree
to the version it describes, a maintainer reviews it, and merging it publishes the release.

While Jason is in alpha this repository takes no pull requests or issues from outside. If something does not work, or
you would like something changed, write to the address in the README's [Getting help](README.md#getting-help); a
vulnerability goes the way [SECURITY.md](SECURITY.md) describes.

Everything here is MIT ([LICENSE](LICENSE)). The runtime binaries attached to each release carry their own licence
inside the archive.
